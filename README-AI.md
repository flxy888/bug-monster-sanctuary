# 狼尊主题 AI 修复

启动演示后保存显示名“狼尊999”，选择项目并编辑当前草稿，点“AI修复”。当前源码会发送至DeepSeek，返回原/新代码预览与摘要。确认后只应用到草稿，再点提交扫描或验证收容；AI本身不保存、不新增扫描、不发XP。

错误、取消或上下文变化会保留原稿。没有页面加载自动调用和付费自动重试。取消等待后，已经发出的上游请求可能继续处理。静态可解析不代表业务正确。

后端优先使用进程环境变量DEEPSEEK_API_KEY，正常启动器在缺少该变量时只为后端进程加载已忽略的.tools/private/deepseek-api-key.txt。DEEPSEEK_MODEL默认deepseek-flash。配置变化后需正常重启本项目后端。密钥文件保留在本机，不放入前端或公开提交。

当前演示JAR为backend/target-week4/sanctuary-0.1.0.jar。源码与测试完整保留；旧AI构建、回退JAR与部署记录在本次项目外历史归档中。日常启动不依赖这些旧文件。

只读预览接口POST /api/projects/{id}/ai-repairs，字段sourceCode，最多20000 UTF-16单位。后端检查项目归属、语法与输出格式，不持有数据库事务等待外部请求。连接/请求有超时与长度限制，单并发且调用起点至少间隔两秒。

此前一次真实调用约3.5秒，示例五规则问题1到0，未改变业务记录；这是单次验证，不是响应时间保证。
